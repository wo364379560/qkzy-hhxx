权限文案详见 `PERMISSION_COPY.md`。统一权限说明已补充具体用途、拒绝影响与设置入口；地图定位和开始运动前的权限申请均增加用途说明，旧版 Android 保存相册时增加写入用途说明。聊天图片/视频和头像沿用系统选择器，不再为选择单个文件额外申请整个媒体库读取权限。

## 界面与入口

- 暖白背景、深蓝名片、陶橙重点，通讯录改为四宫格快捷入口。
- 底部：运动、消息、通讯录、我的；首次进入默认运动。
- 我的：实名认证、登录设备管理、设备保护、帮助与反馈。协议集中在隐私与安全，协议列表增加图标。
- 华为设备的消息页固定展示反诈公告，消息页为一行置顶入口，点开列出 `assets/fanzha1.txt` 至 `fanzha4.txt` 四篇公告，再进入全文。文案来自上级目录对应文件，仅将产品名替换成睿之禾并合并多余空行。
- 华为设备进入主页时读取 `/notices/anti-fraud`，后台开启且正文非空时展示防诈弹框。正文可滚动；倒计时采用后台 `countdown_sec`（限制 0～120 秒，缺失默认 7 秒），后台停留不计入阅读时间，倒计时结束才可点击“我已知晓”，返回键和点击遮罩不能跳过。按账号保存已确认正文的 SHA-256，同版不重复弹，更新正文后重新提示。非华为不请求也不展示；请求失败不阻塞主页，下次进入重试。通知权限申请排在公告处理后。
- 聊天页按服务端 `feature_enabled` 与 `verified` 显示自己未实名、对方未实名提示，不把请求失败当作认证成功。

## 地图配置

iOS 使用高德；Android 已接高德地图 SDK。请在本项目 `local.properties` 中配置：

```properties
AMAP_API_KEY=你的高德Android平台Key
```

也可使用 Gradle 属性 `-PAMAP_API_KEY=...`。不要填写 iOS Key。

2026-09-20 已将用户提供的 Android Key 写入本机 `local.properties`，确认 debug/release 合并后的 Manifest 均包含该 Key，重新构建并通过 release 签名校验。华为手机已覆盖安装新版，运动页已显示“开启地图”，待用户本人阅读地图服务说明并开启后继续验证底图鉴权与显示。

Key 绑定包名为本项目包名，release 证书 SHA-1：

`64:70:2E:EC:C3:B5:48:EF:2C:C0:FE:8E:67:32:45:86:BF:01:0D:C8`

手机当前安装的是调试签名版。如需在调试版验收地图，同一高德应用还需绑定 debug SHA-1：`79:7F:39:42:D6:93:8E:53:D0:36:44:99:FE:D7:23:7C:EE:D0:E4:85`。

未配置 Key 时显示真实 GPS 轨迹预览及地图不可用说明；不会绘制模拟路线。配置 Key 后，用户同意高德服务说明才初始化 SDK。轨迹使用系统 GPS 的 WGS84 坐标，高德展示时转换为对应地图坐标。

当前城市定位补充：开启地图并允许定位后，运动页会在前台通过高德单次定位获取当前位置与城市，并将地图居中；不需要先开始运动。增加“定位到我”按钮、位置标记、精度范围及定位失败提示。离开页面或进入后台时取消未完成定位，回到前台重新获取，历史轨迹回顾不主动定位。此定位不写入运动记录；高德 GCJ-02 结果直接用于地图，仅 WGS84 结果转换，避免重复偏移。定位 SDK 的 APSService 已注册。

检测到系统定位关闭时，显示“开启系统定位”并跳转系统位置设置；监听系统定位开关变化，开启后重新定位。真机初次检查发现 App 已获定位权限，但系统定位关闭；用户开启后已验证地图从默认北京移动到真实定位位置，并显示蓝色位置标记和精度范围，未启动运动、轨迹点仍为 0。本次 SDK 只返回坐标未返回城市文字，标题按设计降级为“当前位置”。最终 debug/release 构建及签名校验通过，首轮定位改动后的 16 项 JVM 测试通过。

## 运动记录

精确定位按需申请。前台定位服务支持切换 Tab、后台记录；手动暂停停止定位，继续后新建轨迹段。过滤过期、低精度与异常速度的定位点；定位丢失超过 30 秒后断段，避免直线跨越缺失路线。按账号保存在应用私有目录，10 秒保存草稿。进程被系统终止后保留最近草稿，不自动恢复录制。结束后查看历史轨迹；退出账号时结束本次录制。

## 服务端接口

沿用 LingDoSpace 协议：`/realname/status`、`/realname/verify`、`/realname/peers`；`GET/PUT /security/settings`；`/devices`、`/devices/revoke`；`/login-challenges/*`。反馈复用 `/reports`，`target_id=app_feedback`。新设备登录支持已登录设备批准/拒绝及短信验证。

设备锁是当前账号在本机的系统凭据锁。开启/关闭需系统身份验证；回到应用时验证后恢复原导航页面。它与云端的新设备登录验证是两个独立开关。
