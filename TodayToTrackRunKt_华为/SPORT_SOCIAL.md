# 运动与聊天联动 · 2026-09-28

## 本轮实现

- 首页仍以运动为第一 Tab，保留系统 GPS 记录，未恢复地图 SDK。
- 增加本周运动里程、次数、打卡天数，统计来自本机记录，不生成虚拟用户、排行或运动数据。
- 运动记录详情增加“分享运动打卡给好友 / 群聊”。选择分享对象后，点击发送才发送消息；失败可重试，发送期间禁止重复点击。
- 默认分享日期、距离、运动时长和配速。用户可选附带轨迹形状，默认分享数据不含经纬度或账号 ID；新版可单独勾选附带起终点的 WGS84 坐标，用于百度地图查看；形状最多 96 个点，保留分段标识。
- 新版使用腾讯云 `createCustomMessage`，业务标识 `rzh_run_v2`，自定义数据包含成绩、路线形状及可选起终点。摘要写入 description；其他客户端是否展示摘要取决于其自定义消息处理逻辑，本轮未修改 Web/iOS。Android 继续兼容旧版文本消息中的 `cloudCustomData.rzh_run_v1`。
- 消息列表增加“运动交流 / 去打卡”，点击返回运动 Tab。
- 消息列表顶部补充自己的实名认证提示：服务端开启实名功能且返回未认证时显示。聊天详情原有本人/对方实名提示保留。
- 华为设备消息页已有固定反诈入口，位于会话滚动列表外，连接 `fanzha1.txt` 至 `fanzha4.txt`。进入主页的华为反诈弹窗逻辑保留。

## 操作流程

开始运动 → 结束并保存 → 运动记录中选中该次记录 → 分享运动打卡 → 选择好友或群聊 → 发送 → 进入聊天 → 点击运动卡片查看详情。

卡片采用深色背景、绿色强调色，突出距离、时间和路线形状。无心率设备数据，因此没有增加虚构心率、卡路里或附近跑者。

## 后续独立功能

约跑活动（时间、地点、距离、报名/取消、组织者管理、活动讨论）、好友动态、评论/举报/拉黑与运动计划可作为下一阶段，需要真实的服务端数据和权限控制。本轮没有把这些功能做成只有入口的占位页面。

## 验证边界

新增 4 项分享协议测试，覆盖隐私字段、体积限制、分段、异常输入、空记录/活动中记录限制。实际双账号收发、不同客户端的回退展示及真机视觉效果仍需验证；代码检查和构建成功不等于华为审核通过。

## 自定义路线卡片补充

聊天「更多 → 分享运动路线」可选本机已保存记录，确认后发送给当前会话，无需再次选择联系人。发送成功后即时更新当前聊天。

详情页在已分享起终点时显示百度地图按钮：优先 `baidumap://map/marker`，未安装时回退 `https://api.map.baidu.com/marker`。明确指定 `coord_type=wgs84`，不把 GPS 坐标当成百度坐标；不嵌入百度 SDK。百度只展示所选起点/终点，完整路线形状在 App 内查看，不能把百度重新规划的道路当成实际跑步轨迹。

用户点击按钮才将该点传给百度；没有坐标的旧卡片不显示按钮。尚未真机验证百度应用/网页调起、双账号自定义消息收发及 Web/iOS 显示。

接口参考：https://lbsyun.baidu.com/docs/webapi?title=mapadjustment%2Furi%2Fandriod 、https://lbs.baidu.com/docs/webapi?title=mapadjustment%2Furi%2Fweb

## 六入口与界面调整

- 底部按“运动 / 计划 / 记录 / 消息 / 通讯录 / 我的”排列。旧消息和联系人 Tab 的逻辑标识保留，避免已有页面跳转含义变化。
- 计划页支持设置每周 5 / 10 / 20 公里目标，按账号在本机保存；读取真实运动记录计算本周进度。
- 记录页独立展示历史列表及路线详情，保留分享。运动首页新增计划和记录快捷卡片，把开始/暂停/结束操作移到轨迹图上方。
- 消息页顺序调整为标题、搜索框、华为反诈公告、会话列表。公告位于会话滚动容器外。消息首页移除实名认证提示和去打卡入口，聊天详情实名提示保留。
- 聊天底部工具增加浅色圆角图标背景与文字标签，更多面板改为运动路线、个人名片、资料三张操作卡。
- 路线选择弹框中每条记录显示里程、时间、“点击选择这条路线”及右箭头，整张卡片可点。

## 日历计划

计划页新增月历，可切换月份、返回今天和选日期；有计划的日期显示条数。同一天可创建多项跑步/步行计划，每项按公里或分钟设定目标，支持备注、编辑日期和目标、删除。

计划以 JSON 按账号隔离保存在本机 SharedPreferences，写入成功后才更新界面；读取失败不会用空数据覆盖旧计划。退出再登录仍保留，清除 App 数据或卸载会丢失，尚无云同步。

完成运动后手动选择计划当天的已保存记录进行关联；不使用未完成的 draft。一个记录只允许关联一项计划。目标达成才显示已完成，未达标显示已关联/未达目标；关联记录可查看轨迹或解除。修改日期或运动类型会清除关联，修改目标后重新计算状态。删除计划不影响运动记录。

新增 RunPlansTest 校验日期（含闰日）、目标范围、序列化还原、记录日期与重复关联、完成进度。尚未真机逐项验收日历界面与重新登录持久化。
